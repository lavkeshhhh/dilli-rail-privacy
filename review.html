What the recording shows

  1. The user opens Live, starts location and accepts the in-app disclosure.
  2. The user creates a private room and shares the estimated metro station with that room.
  3. The user leaves the app; an ongoing notification makes the active service visible. Tapping Stop ends the service and sharing.
  4. The user starts the GPS journey companion, sees the next stop in the notification while outside the app, and receives station-by-station progress.
  5. Arrival completes the journey and automatically stops location when no room sharing is active.

Recorded on a dedicated Android 16 emulator using the unchanged, signed APK generated from the submitted Android App Bundle. Station fixes are synthetic test inputs; this is not a real journey or a demonstration of physical GPS accuracy. Android location and notification permissions were granted before recording. The app's own location disclosure is shown. The temporary demonstration room is closed after use; no real users or private locations are included.

Why an ongoing service is used

Only a user-started live session, room-sharing session or journey enables the location foreground service. It keeps estimated station sharing and journey progress available when the app is no longer in the foreground. Deferring or interrupting it would delay updates to invited room members and station guidance. Users can stop at any time with the notification's Stop control. The application does not request the Android background-location permission.
